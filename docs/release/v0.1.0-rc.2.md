# VERA-MMU v0.1.0-rc.2 — Préversion expérimentale

> **Attention — préversion gratuite et non signée.** Ces binaires sont destinés à des testeurs avertis. Windows peut signaler un éditeur non vérifié. Vérifiez systématiquement les SHA-256 et les manifests fournis avant exécution. Cette préversion ne doit pas être traitée comme une release stable ni déployée dans un environnement critique.

> **Historique de version :** `v0.1.0-rc.1` est un tag de validation non publiable. Son run de tag a mis en évidence une contrainte MSI : l’identifiant de préversion du binaire Windows doit être exclusivement numérique. `v0.1.0-rc.2` corrige ce packaging en employant l’identité de binaire `0.1.0-2` tout en conservant le tag lisible rc.2.

VERA-MMU est un moteur local de mémoire, de provenance et de gouvernance vérifiables pour projets assistés par IA. Cette première préversion publie le Core universel, la CLI `vmmu` autonome, le bridge desktop stdio, l’application Tauri Windows/Linux et les adapters project-local.

## Vérifier avant utilisation

Téléchargez l’archive de votre plateforme et vérifiez les hashes dans le répertoire qui contient `SHA256SUMS` :

```bash
# Linux / Git Bash / environnement disposant de sha256sum
sha256sum -c SHA256SUMS
```

Sous PowerShell, comparez chaque résultat avec `SHA256SUMS` :

```powershell
Get-FileHash .\nom-du-fichier -Algorithm SHA256
```

Le manifest référence le tag, la révision source, la plateforme, les tailles et les hashes. Un hash divergent, un manifest absent ou une archive incomplète impose de **ne pas exécuter** le fichier.

## Parcours de test conseillé

Commencez par la CLI sur une copie ou un projet d’essai : `vmmu scan <dossier>`, puis `vmmu init-project` sans `--apply` pour lire la preview. Appliquez seulement après vérification, avec `--apply --confirm`. L’installation MCP suit la même règle : preview, fraîcheur, confirmation, écriture atomique ou refus.

L’application desktop permet le même parcours par interface : lancer, choisir un dossier, scanner, choisir le template, vérifier la preview et confirmer. Elle ne donne pas au frontend le droit de parcourir arbitrairement le disque ni de lancer un shell.

## Limites connues

Cette préversion est validée par la suite automatisée et par les runners Windows x64/Linux x64, mais **elle ne prouve pas encore** une installation sur machine d’utilisateur ni un fonctionnement live avec Claude, Codex, Gemini ou Antigravity. Les adaptateurs restent testés par contrats et fixtures. GitHub Pages/viewer public, macOS, ARM, mise à jour automatique, signature de code et support de production ne font pas partie de `v0.1.0-rc.2`.
