# Politique de marque VERA-MMU

Le code source de VERA-MMU est disponible sous Apache-2.0. Cette licence ne concède pas de droit sur les noms, logos, symboles visuels ou identités de release du projet.

Les termes **VERA-MMU**, **Verifiable Epistemics & Relational Architecture**, le logotype et les visuels associés peuvent être utilisés de manière descriptive et honnête pour désigner le projet d’origine ou une compatibilité réelle. Ils ne peuvent pas être utilisés pour laisser entendre qu’un fork, un paquet modifié ou un service tiers est une release officielle, certifiée, soutenue ou approuvée par Aciderix.

Une distribution peut être dite « officielle VERA-MMU » uniquement si elle est publiée par l’organisation GitHub `aciderix`, rattachée à une release VERA-MMU identifiée et accompagnée des hashes et signatures annoncés dans ses notes. Les forks doivent choisir un nom et une identité visuelle qui évitent toute confusion raisonnable.

Cette politique décrit un usage de marque de projet ; elle ne prétend pas établir l’enregistrement d’une marque dans une juridiction donnée.
